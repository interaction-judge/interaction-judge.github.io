VoxelCraft

A self-contained, original block sandbox inspired by classic voxel survival games. No external assets, no libraries — everything is generated inside this one HTML file.

Controls

Click lock mouse / start
WASD move, Space jump, Shift sprint/sneak
Left click mine, Right click place, Mouse wheel block
1-9 hotbar, E inventory, C craft
F toggle fly, R respawn, P save, L load
M map/biome scan, F3 debug, Esc pause

Features

Procedural terrain, biomes, caves, ores, trees, flowers, cactus, water, lava, snow, glass, torches, beds, doors, TNT, tools, mobs, farming, day/night, weather, creative/survival, local save/load, ray-cast mining, block physics, inventory, simple crafting, particles and sounds.

Inventory

Click a block to equip it in the selected hotbar slot. In survival, mined blocks and crafted items accumulate here.

Crafting

Simple one-click recipes. Survival consumes ingredients; creative crafts freely.

You Died

The world keeps going.
